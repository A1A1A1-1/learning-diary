# 学习日记 - 2026年5月27日

## 今天学了什么

### Agent Token + GitHub
- Token 是一把数字钥匙，让 AI Agent 能替你操作 GitHub
- Classic Token vs Fine-grained Token：前者权限粗，后者能精确控制
- Agent Token 的核心价值：你授权，Agent 替你干活，操作记录在你名下

### AI + GitHub 的玩法
- 第一层：Copilot 代码补全（最简单）
- 第二层：Copilot Agent 模式 / Claude Code（AI 自己规划执行）
- 第三层：Agentic Workflows（用 Markdown 写 AI 自动化）
- 第四层：全自动流水线（Issue → 代码 → PR）
- 第五层：用自己的 Agent Token 让巴特鹿帮忙管 GitHub

## 关键概念
- **Agent**：替你干活的智能体，能自主思考和行动
- **Token**：数字钥匙，代表身份和权限
- **GitHub**：代码托管平台，程序员的协作空间
